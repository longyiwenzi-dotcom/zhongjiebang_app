架构与取舍

线上模块化单体

2 GB 公网服务器只运行一个 Java 进程。用户、房源和会员按领域拆分模块，共享数据库事务，降低内存与运维成本。

本地 Spring Cloud

Gateway、Nacos、OpenFeign、Sentinel、Redis、RabbitMQ、Zipkin 与 Seata 用于服务治理和分布式场景演示。

统一身份入口

Gateway 删除外部 X-User-Id，根据 Redis 中的会话摘要写入可信身份，防止客户端伪造用户编号。

失败策略

会员服务故障时默认拒绝详情访问。系统无法确认权限时不放行付费数据。

核心调用链

01 登录BCrypt 校验密码
02 会话Redis 保存令牌摘要
03 房源MySQL 分页筛选
04 权限会员额度事务扣次
05 审计RabbitMQ 异步记录

功能、接口与服务

密码与令牌

密码使用 BCrypt cost 12。访问令牌为随机不透明字符串，Redis 只保存 SHA-256 摘要并设置 12 小时有效期。

房源隐私

普通用户看到上传人电话；房东电话和具体地址只向房源上传人返回。ownerId 始终来自认证上下文。

会员并发

用户级行锁串行化扣次，唯一索引保证同一房源当天只扣一次。周卡每日 10 次，月卡每日 30 次。

一次性兑换码

数据库只保存 26 位兑换码摘要。带 used_at is null 的条件更新确保并发消费只有一个请求成功。

Seata 跨库事务

会员库和兑换码库分别维护 undo_log。XID 通过 Feign 传播，会员延期失败时回滚兑换码消费。

异步浏览历史

House 发布 house.viewed 事件，Audit 服务异步落库。生产版本应继续引入 Outbox 保证事件可靠发布。

数据库索引

房源按租售状态与时间索引；扣次表使用用户、房源、日期唯一索引；浏览历史按用户和时间倒序索引。

测试与 CI

包含单元测试、Spring 集成测试、网关鉴权测试以及 MySQL/Redis Testcontainers。GitHub Actions 每次提交自动验证。
